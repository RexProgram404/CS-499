The artifact is a program that takes in a list of class names and prerequesits and stores them into a Hashtable and node data structure, sorted, with the ability to save the list into a .csv file. This program was created for a project for the CS 300 class, where we were tasked to choose one of three different data structures and to create a program to take a file listing classes and their prerequisites and to save it into a .csv file. This program was originally created in October 2025. The inclusion of the artifact in this ePortfolio is to demonstrate my ability to create and utilize data structures, specifically Hashtables and node trees. I had enhanced the program by modulating the majority of the main method, reducing the amount of code in the main method and creating new functions that are modular and portable. The enhancement shows my ability to modify code with data structures without compromising the integrity of the data structure. While creating this program I learned about how creating data structures worked and how they can interact with each other, in this case hashtables and nodes. The main challenge I faced when enhancing the program was recalling pointers in parameters for C++ as it has been a fair amount of time since I last programed in it. The outcome that I set out for this artifact was to make it usable in more scenarios than what the assignment that it was created for required, and I believe that I have partially achieved this goal however, the only goal that was not met was that this program still is just a class name sorter, only now it can handle more files that originally intended.
