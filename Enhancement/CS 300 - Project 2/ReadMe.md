Intalling the Program:

To install the program, simply download the program and import the class list that you want to be sorted. The other files in the program are used as default file for the program to access but are not required for the program to run.

Running the Program:

To run the program, first enable the "/CS 300 - Project 2/ Project_2" file to be a runnable program, then import the files that you want to sort into the folder with the program, and start the program through the terminal or command console.
