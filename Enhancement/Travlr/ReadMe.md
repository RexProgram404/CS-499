Installing the program:

To install the program, you will need to download the program, as well as Nodejs to run the website and MongoDB to run the database.

Running the program:

To run the program you will first need to open a terminal or command console and to navigate to the Travlr folder. Then you will need to run npm start in the Travlr folder to start the website on a localhost. To run the database you will need to run "sudo systemctl start mongod" for linux or "net start MongoDB" for windows. The default port for the website is port 3000.
